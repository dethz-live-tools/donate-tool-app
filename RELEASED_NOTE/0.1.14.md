# donate-socket Release Notes - v0.1.14

**Release Date:** 2026-11-14  
**Version:** 0.1.14  
**Bump Type:** patch

## Summary

Security hardening for SSRF and loopback validation, covering `127.0.0.0/8`, null address `0.0.0.0`, and IPv6 `[::]` across webhooks and external overlay layers.

## What's Changed

### Fixed
- Hardened loopback resolution in webhook dispatch and OBS external iframe overlays: addresses in `127.0.0.0/8` (such as `127.0.0.2`), null address `0.0.0.0`, and IPv6 unspecified address `[::]` targeting the internal bridge API port are now blocked consistently across backend services, OBS runtime HTML, and UI input validation.
- Added regression test cases in `server/studio.test.ts` for expanded loopback and null address patterns.

## Key Files Changed
- `server/services/webhook.ts` — loopback validation in `validateWebhookUrl()`.
- `server/config.ts` — loopback filtering in `isValidExternalLayerUrl()`.
- `server/routes/overlays.ts` — OBS runtime HTML iframe loopback check.
- `src/components/StudioTab.tsx` — UI layer URL validation.
- `server/studio.test.ts` — regression test assertions.
- `package.json`, `src-tauri/tauri.conf.json`, and `src-tauri/Cargo.toml` — version 0.1.14.
