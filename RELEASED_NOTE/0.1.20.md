# donate-socket Release Notes - v0.1.20

**Release Date:** 2026-11-23  
**Version:** 0.1.20  
**Bump Type:** patch

## Summary

Security hardening release addressing white-box audit findings (`VULN-2026-022`–`025`), enforcing symlink containment on static overlay serving, origin-scoped CORS across WHIP/bridge endpoints, atomic TLS key/certificate persistence, safe URL parsing, and concurrent socket/SSE limits.

## What's Changed

### Added
- **Security & WHIP CORS Regression Tests** (`tests/security.test.ts`, `server/screenShare.test.ts`): Added automated assertions covering `isAllowedOrigin()`, `parseRequestUrl()`, malformed percent-encoding handling, static overlay symlink traversal rejection, `MAX_STATUS_SSE_CLIENTS` capping, WHIP cross-origin blocking, and TLS key symlink rejection.

### Changed
- **Shared Origin & Safe Request URL Helpers** (`server/utils.ts`, `server/index.ts`): Moved `isAllowedOrigin()` into side-effect-free `server/utils.ts` and introduced `parseRequestUrl()` so malformed `Host` headers degrade safely for origin-form requests while invalid targets return HTTP `400`.
- **Documentation Sync** (`docs/security-audit.md`): Documented security controls `1.18`–`1.21` (`VULN-2026-022`–`025`).

### Fixed
- **Static Overlay Symlink Traversal & ZIP Staging (`VULN-2026-022`)** (`server/routes/overlays.ts`, `server/services/overlays.ts`): Guarded `decodeURIComponent()` with HTTP `400`, enforced `fs.lstatSync` symlink rejection and `fs.realpathSync` containment (`403`) on `GET/HEAD /overlays/*`, and moved remote ZIP extraction staging into an isolated `0o700` `fs.mkdtempSync()` working directory.
- **WHIP CORS Origin Bypass on `:3002` and `:3001` (`VULN-2026-023`)** (`server/services/screenShare.ts`, `server/index.ts`): Replaced unconditional `Access-Control-Allow-Origin: *` with `isAllowedOrigin()` checks (allowing native non-browser clients without `Origin` and loopback/Tauri/LAN origins, while blocking untrusted public web origins with HTTP `403` on preflights, `/whip*`, and state-changing requests).
- **Atomic TLS Key/Certificate Persistence (`VULN-2026-024`)** (`server/services/tlsCert.ts`): Verified `isRegularNonSymlinkFile()` before reading cached PEMs and replaced direct writes with unique `flag: "wx"` temporary files plus atomic `fs.renameSync()` swaps.
- **Connection & SSE Exhaustion Bounds (`VULN-2026-025`)** (`server/services/screenShare.ts`, `server/routes/status.ts`): Capped `:3002` TCP multiplexer client sockets (`MAX_WHIP_CLIENT_SOCKETS = 100`) and `/api/events` / `/api/status/stream` SSE listeners (`MAX_STATUS_SSE_CLIENTS = 100`, HTTP `503`) with `close`/`error` stream cleanup.
