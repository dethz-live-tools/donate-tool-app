# donate-socket Release Notes - v0.1.12

**Release Date:** 2026-11-13  
**Version:** 0.1.12  
**Bump Type:** patch

## Summary

Dedicated webhook endpoints for chat/TTS and Spotify events, and Windows portable bundle packaging in release builds.

## What's Changed

### Added
- Split webhooks: `webhook.uri` delivers gifts; optional `webhook.uri_chat` (TikTok chat/TTS) and `webhook.uri_spotify` (Spotify) endpoints, each falling back to the main gift URL when empty.
- Dedicated webhook inputs in the Config tab UI for chat/TTS and Spotify endpoints.
- Windows release workflow bundles now build NSIS, MSI, and portable targets.

## Key Files Changed
- `server/services/webhook.ts` — per-type webhook URL routing (gift/tts/spotify).
- `server/config.ts` — persistence and migration for `webhook.uri_chat` and `webhook.uri_spotify`.
- `src/components/ConfigTab.tsx` — UI configuration fields for split webhooks.
- `src/App.tsx` and `src/types.ts` — frontend state and type support for dedicated webhook URIs.
- `.github/workflows/release.yml` — Windows bundle argument `--bundles nsis,msi,portable`.
- `package.json`, `src-tauri/tauri.conf.json`, and `src-tauri/Cargo.toml` — version 0.1.12.
