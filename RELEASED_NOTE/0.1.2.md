# Release Notes - v0.1.2

**Release Date:** 2026-11-11  
**Version:** 0.1.2  
**Bump Type:** patch

## Summary
Release `v0.1.2` introduces the Overlays Marketplace & static server, Spotify Song Request integration with TikTok chat (`!sr`), Edge TTS chat reader with natural Thai voices (`th-TH-NiwatNeural`), top-level webhook `event` categorization, TikTok gift combo-end filtering, and persistent debounced `config.yaml` synchronization.

## What's Changed

### Added
- **Overlays Marketplace & Static Server**: Built-in overlay catalog, one-click installation, custom HTML/CSS overlay creation, and local HTTP static serving.
- **Spotify Song Request Queue**: Viewers can request songs live via `!sr [song or Spotify URL]`; streamer can search and queue tracks directly.
- **TikTok Chat Reader & Neural Edge TTS**: Real-time chat speech synthesis powered by Microsoft Edge TTS with high-quality Thai voices (`th-TH-NiwatNeural` & `th-TH-PremwadeeNeural`).
- **Webhook Event Differentiation**: Top-level `event` field added to all outgoing webhook dispatches (`"tiktok_gift"`, `"tts"`, `"spotify_status"`).
- **TikTok Gift Combo-End Dispatching**: Consecutive gifts (combos) are aggregated and sent as a single webhook event when the combo finishes.
- **Dashboard Panel Controls**: Collapsible panel toolbar with individual minimize/expand states and summary previews.

### Changed
- **Unified YAML Configuration**: All application settings (TikTok, Spotify, TTS, and UI minimization) now save and synchronize directly with `config.yaml`.
- **Curated Edge TTS Voice Registry**: Instant 0ms response for voice queries with pre-cached natural Thai and English voice profiles.

### Fixed
- **TTS Synthesis Timeouts & Voice Errors**: Replaced 60s socket hangs with fast timeouts, automatic Thai language fallback to Niwat, and eliminated macOS Web Speech API errors.
- **Settings Slider Debouncing**: Buffered and debounced configuration updates by 350ms to prevent disk write collisions and state resets during slider adjustments.
- **TikTok Live Connector Migration**: Fixed TikTok connection failures and bypassed Euler stream paywall restrictions.

## Key Files Changed
- `server/services/tts.ts` - Edge TTS synthesis engine, language routing, and voice cache
- `server/services/tiktok.ts` - TikTok gift combo-end accumulator and live connection handler
- `server/routes/overlays.ts` & `server/services/overlays.ts` - Overlay marketplace API and static file serving
- `server/config.ts` - Bi-directional YAML serialization and synchronization
- `src/components/DashboardTab.tsx` - TTS reader bar, song requests, payload specs, and debounced controls
- `src/components/OverlaysTab.tsx` - Overlay market browser, custom creator, and previewer
