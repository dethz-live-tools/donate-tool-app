# donate-socket Release Notes - v0.1.16

**Release Date:** 2026-11-16  
**Version:** 0.1.16  
**Bump Type:** patch

## Summary

Separate webhook logs by event type (TikTok gift, TTS/chat, Spotify) with filter tabs, and a one-command full build script.

## What's Changed

### Added
- Log filter tabs (ALL / GIFT / TTS / SPOTIFY) in the webhook dispatch log box; each tab shows only its event type (GIFT also includes test webhooks).
- `build:full` script (`package.json`) — chains frontend build, backend binary compile, and Tauri release bundle.

### Fixed
- Server log storage now retains up to 50 entries per type, so gift volume can no longer evict TTS or Spotify log entries (total cap 250).

## Key Files Changed
- `server/services/webhook.ts` — per-type log retention (`pushLog`).
- `src/components/DashboardTab.tsx` — log filter state, tabs, filtered list.
- `src/App.css` — log filter row styles.
- `package.json` — `build:full` script.
- `package.json`, `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml` — version 0.1.16.
