# Release Notes - v0.1.1

**Release Date:** 2026-11-10  
**Version:** 0.1.1  
**Bump Type:** patch

## Summary
Initial release of `donate-socket` featuring real-time TikTok LIVE gift webhook forwarding, rich Spotify playback controls with live queue inspection and device switching, automatic Spotify status webhook dispatching, RawBlock brutalist UI with Sapphire accents and Thai font fallback, and multi-platform CI/CD automation.

## What's Changed

### Added
- Real-time TikTok LIVE donation & gift listener bridge with SSE status broadcast
- Full Spotify integration: Now Playing track card, player controls, live queue list, and device switcher
- Spotify status webhook dispatching on track transitions and playback state updates
- RawBlock brutalist design system using Catppuccin Macchiato palette with Sapphire accent (`#7dc4e4`)
- IBM Plex Sans Thai font fallback integration across all typography stacks
- Multi-OS GitHub Actions release workflow targeting macOS (Apple Silicon & Intel), Linux, and Windows
- Comprehensive documentation suite covering architecture, webhooks, Spotify setup, and releases

### Changed
- Refactored backend into modular `server/` routes and services with persistent YAML configuration
- Upgraded dev runner (`dev.ts`) with live watch mode for backend server files
- Enhanced payload specification viewer in Dashboard with dual TikTok and Spotify schema tabs

### Fixed
- TypeScript type-only interface exports for Bun/Node runtime compatibility
- Webhook logging and error reporting reliability

## Key Files Changed
- `server/services/spotify.ts` - Spotify OAuth, queue discovery, device switching, and status webhook dispatch
- `server/routes/spotify.ts` - REST endpoints for devices, queue, player controls, and test webhooks
- `src/components/DashboardTab.tsx` - Interactive player card, device dropdown, live queue list, and payload specs
- `src/App.css` - RawBlock brutalism styling, Sapphire accent, and Thai font fallback
- `.github/workflows/release.yml` - Multi-OS GitHub release workflow
- `README.md` & `docs/*` - Full documentation suite
