# donate-socket Release Notes - v0.1.10

**Release Date:** 2026-11-12  
**Version:** 0.1.10  
**Bump Type:** patch

## Summary

Desktop builds launch a bundled backend and use a stable writable YAML configuration file instead of relying on the process working directory.

## What's Changed

### Added
- Standalone Bun backend packaging for desktop releases.
- Credential-free bundled YAML template for first-run configuration.
- Explicit configuration and template paths through `DONATE_CONFIG_FILE` and `DONATE_CONFIG_TEMPLATE`.
- Isolated regression coverage for stable configuration paths and persistence.

### Fixed
- Installed desktop apps no longer depend on a repository-relative backend or launch directory to find configuration.
- Configuration changes update the same app-data `config.yaml` used for reads.
- Existing configuration is preserved rather than replaced by bundled defaults.
- Atomic writes protect against partial configuration replacement.
- The settings API reports persistence failures before changing live settings.

## Key Files Changed
- `server/config.ts` and `server/config.test.ts` — stable YAML paths and safe persistence.
- `server/routes/status.ts` — failed-save response.
- `src-tauri/src/lib.rs` — resource-based backend launch and writable app data.
- `scripts/build-backend.ts`, `package.json`, and `src-tauri/tauri.conf.json` — executable build and resources.
- `docs/build-and-release.md` — configuration paths and migration instructions.
- `src-tauri/Cargo.toml` and `src-tauri/Cargo.lock` — version 0.1.10.
