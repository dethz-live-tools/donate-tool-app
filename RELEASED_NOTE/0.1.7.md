# donate-socket Release Notes - v0.1.7

**Release Date:** 2026-11-12  
**Version:** 0.1.7  
**Bump Type:** patch

## Summary

Overlay Studio supports external HTTP/HTTPS overlays as iframe layers in the editor and OBS composed scenes.

## What's Changed

### Added
- External overlay URL and optional name controls.
- External layers that use the existing positioning, resizing, ordering, visibility, opacity, and profile persistence.
- HTTP/HTTPS URL validation and sandboxed external iframe rendering without referrer headers.

### Changed
- Scene normalization and OBS rendering preserve valid external layer URLs, including query parameters.

## Key Files Changed
- `src/components/StudioTab.tsx` and `src/types.ts` — external layer controls and editor rendering.
- `server/config.ts`, `server/types.ts`, and `server/routes/overlays.ts` — URL normalization, persistence, and OBS rendering.
- `server/studio.test.ts` — external layer validation and runtime coverage.
- `docs/overlays.md` — usage, trust boundaries, and iframe limitations.
- `package.json` and `src-tauri/` version metadata — version 0.1.7.
