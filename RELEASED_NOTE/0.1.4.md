# donate-socket Release Notes - v0.1.4

**Release Date:** 2026-11-12  
**Version:** 0.1.4  
**Bump Type:** patch

## Summary

The navigation can collapse to reclaim main-content width. Overlay Studio adds larger editing and preview workspaces plus named layouts with dedicated OBS links.

## What's Changed

### Added
- Accessible collapse/expand navigation controls with compact page shortcuts.
- Expand/restore controls for the Studio editor and preview, with Escape support.
- Persisted named Studio profiles, each with an independent canvas and stable OBS Browser Source URL.
- Profile selection, creation, and copy/open link controls in Overlay Studio.

### Changed
- Main content uses the available window width instead of a fixed maximum width.
- Profile-specific OBS sources follow their own saved scene over live updates, independently of editor selection.
- Master scene save failures propagate to Studio instead of appearing successful.
- Existing master scene URLs remain supported.

## Key Files Changed
- `src/components/Sidebar.tsx` and `src/App.css` — compact navigation and expanded workspace layouts.
- `src/components/StudioTab.tsx` — profile controls and workspace expansion.
- `src/App.tsx` — master save failure propagation.
- `server/config.ts`, `server/types.ts`, and `server/routes/overlays.ts` — profile persistence, API, and OBS rendering.
- `server/studio.test.ts` — focused scene profile coverage.
- `docs/overlays.md` — workspace and profile usage.
- `package.json` and `src-tauri/` version metadata — version 0.1.4.
