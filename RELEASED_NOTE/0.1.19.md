# donate-socket Release Notes - v0.1.19

**Release Date:** 2026-11-22  
**Version:** 0.1.19  
**Bump Type:** patch

## Summary

Added the LAN WHIP WebRTC screen-share receiver (with same-port HTTP + self-signed HTTPS built-in web sharer and OBS Browser Source overlay), enabled LAN (`0.0.0.0`) hosting across bridge and Vite dev/preview servers, automated outdated backend replacement on startup, and resolved seven white-box security findings (`VULN-2026-015`–`021`).

## What's Changed

### Added
- **LAN WHIP Screen Share Receiver** (`server/services/screenShare.ts`, `server/routes/screenShare.ts`, `src/components/ScreenShareTab.tsx`, `src/lib/screenShareClient.ts`): Added RFC 9725 WHIP ingest (`POST /whip`, `PATCH`, `DELETE`), built-in browser screen sharer (`/share`, `/screen`, `/`), transparent `/overlays/screen-share/` OBS Browser Source with hover mute/volume HUD and WebRTC mirroring, and Thai/English localization (`src/i18n.tsx`, `server/screenShare.test.ts`).
- **Same-Port HTTP + Self-Signed HTTPS TLS Multiplexer** (`server/services/tlsCert.ts`): Generated and persisted EC `prime256v1` X.509 certificates (`screen-share-cert.pem` / `screen-share-key.pem` next to `config.yaml`, gitignored in `.gitignore`) with LAN IP SANs so LAN browsers run `getDisplayMedia()` in a Secure Context on port `3002`.
- **Full LAN Hosting & Dynamic Client Routing**: Added `HOST` (`0.0.0.0` default), `getLanAddresses()`, and `isPrivateOrLanHost()` (`server/utils.ts`), dynamic `resolveApiBase()` (`src/lib/apiBase.ts`), and `vite.config.ts` LAN bindings (`server` `:1420`, `preview` `:4173`) plus `/share`, `/screen`, and `/whip` proxy paths.
- **Screen Share User Guide**: Added `docs/screen-share-whip.md` and expanded `tests/security.test.ts`.

### Changed
- **Backend Revision Detection & Lifecycle Management** (`dev.ts`, `src-tauri/src/lib.rs`, `vite.config.ts`): Check `apiRevision` (`5`) at startup to terminate and replace outdated bridge processes on port `3001`, track Tauri child processes in `BackendProcess` for clean shutdown (`stop_managed_server`), and run `vite.config.ts` auto-spawned server with `--watch`.
- **Config Persistence & Masking** (`server/config.ts`, `server/types.ts`, `src/types.ts`): Added `screen_share` configuration (`enabled`, `port`, `token`) with token masking in public config.
- **Documentation Sync**: Updated `README.md` and `docs/` (`architecture.md`, `latest-features.md`, `overlays.md`, `build-and-release.md`, `security-audit.md`) for v0.1.19 features, LAN hosting, and security remediations.

### Fixed
- **Overlay Git/ZIP Importer Hardening (`VULN-2026-015`)** (`server/services/overlays.ts`): Replaced shell `exec()` with `execFile()`, validated HTTP(S) repo URLs (`validateRemoteRepoUrl`, `fetchSafeZipResponse` with max 3 validated redirects and 25 MiB limit), disabled Git symlinks, skipped archive symlinks with containment checks, and HTML-escaped fallback metadata.
- **WHIP Bearer Token Isolation & Peer Bounds (`VULN-2026-016`)** (`server/services/screenShare.ts`, `server/routes/screenShare.ts`): Masked `token` (`""`) on `"obs"` SSE `welcome`/`status` payloads, capped `MAX_RECEIVER_PEERS = 50`, destroyed oversized SDP streams, and added `X-Content-Type-Options: nosniff`.
- **Spotify OAuth CSRF State & XSS Fix (`VULN-2026-017`)** (`server/routes/spotify.ts`): Switched `expectedOAuthState` to `randomBytes(24)`, required mandatory constant-time `timingSafeEqual()` verification on every callback, and HTML-escaped callback error output.
- **Edge TTS SSML Sanitization (`VULN-2026-018`)** (`server/services/tts.ts`, `server/routes/tts.ts`): Enforced voice regex, rate/pitch range clamping, XML attribute escaping, and a `1000`-character text cap.
- **Stream Limits & CORS Tightening (`VULN-2026-019`)** (`server/utils.ts`, `server/routes/status.ts`): Destroyed over-1 MiB JSON request streams (`parseJsonBody`), excluded `169.254.*` and `fe80:` from LAN/CORS helpers, and preserved Origin-scoped CORS headers on SSE routes.
- **Self-LAN SSRF Guard & Loopback Folder Access (`VULN-2026-020`, `VULN-2026-021`)** (`server/utils.ts`, `server/config.ts`, `server/services/webhook.ts`, `server/routes/overlays.ts`, `src/components/StudioTab.tsx`): Blocked self-LAN IP port `3001` targeting and restricted `/api/overlays/open-folder` to loopback sockets (`403` from remote LAN).
