# donate-socket Release Notes - v0.1.11

**Version:** 0.1.11  
**Bump Type:** patch

## Summary

In-app update checking against the GitHub releases of this repository. The app now reports when a newer version is available and links to the release page.

## What's Changed

### Added
- In-app update checker: polls the GitHub `releases/latest` API on launch and compares against the running version.
- Dismissible update banner with a direct link to the newest release page.
- New ABOUT page (sidebar tab) showing app version, update status, and a manual "check for updates" button.
- Role-based bot access: TTS read-out and chat bot commands (`!sr`) can be restricted per TikTok user role (owner, moderator, subscriber, follower, guest) via the chat reader settings.

### Changed
- App version is injected at build time via Vite (`__APP_VERSION__`) so update checks stay accurate per build.
- Spotify player poll reduced from 3s to 15s (5x fewer API calls); removed now-playing time/progress display.

### Fixed
- TikTok gift price now uses the connector's `gift.diamondCount` field. Previously only the never-populated `gift.diamond_count` was read, so every gift fell back to `1` and coins were just the repeat count.

## Key Files Changed
- `src/App.tsx` — update check, version comparison, update banner, and page routing.
- `src/components/AboutTab.tsx` — new ABOUT page with version and update status.
- `src/components/DashboardTab.tsx` — TTS role gating and role-access UI.
- `server/services/tiktok.ts` — role detection and TTS/command role gates.
- `src/components/Sidebar.tsx` — ABOUT sidebar tab.
- `server/services/tiktok.ts` — corrected gift `diamondCount` source (coins = price × repeat).
- `server/services/spotify.ts` — poll interval 3s → 15s.
- `src/components/DashboardTab.tsx` + `src/App.css` — removed now-playing time/progress UI.
- `vite.config.ts` — inject `package.json` version into the frontend bundle.
- `src/vite-env.d.ts` — typed `__APP_VERSION__` global.
- `package.json` and `src-tauri/tauri.conf.json` — version 0.1.11.
