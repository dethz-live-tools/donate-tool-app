# donate-socket Release Notes - v0.1.5

**Release Date:** 2026-11-12  
**Version:** 0.1.5  
**Bump Type:** patch

## Summary

Studio editor links now select saved profiles through query parameters. A profile link tools box loads a saved profile from a pasted editor or OBS URL.

## What's Changed

### Added
- Editor deep links using `?page=studio&profile=<id>`.
- Profile link tools with URL loading and editor-link copying.
- Validation for pasted HTTP/HTTPS URLs and missing profile parameters.

### Changed
- Profile selection updates the current editor URL.
- Opening a profile query link selects Studio and loads that saved profile.

## Key Files Changed
- `src/App.tsx` — query-aware initial page.
- `src/components/StudioTab.tsx` — query loading, URL tools, and editor links.
- `docs/overlays.md` — link usage and local-server scope.
- `package.json` and `src-tauri/` version metadata — version 0.1.5.
