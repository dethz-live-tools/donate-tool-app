# Release Notes - v0.1.3

**Release Date:** 2026-11-11  
**Version:** 0.1.3  
**Bump Type:** patch

## Summary
Release `v0.1.3` introduces **Overlay Studio**, a visual drag-and-drop scene composer that merges and arranges multiple stream overlays onto a single transparent OBS Browser Source (`http://127.0.0.1:3001/overlays/studio/`) with real-time SSE layout updates.

## What's Changed

### Added
- **Overlay Studio Composer (`StudioTab`)**: Interactive visual stage with pointer drag-to-move, corner drag-to-resize, 10px grid snapping, resolution presets (`1920×1080`, `1280×720`, `1080×1920` TikTok Vertical), custom dimensions, Z-order layer stack, visibility/lock toggles, scale/opacity sliders, and quick corner/center alignment.
- **Unified OBS Studio Scene Endpoint (`/overlays/studio/`)**: Transparent HTML scene renderer hosting positioned overlay iframes that auto-fits the OBS Browser Source viewport and updates positions, sizes, opacity, and layers live over `/api/events` SSE without reloading active widgets.
- **Studio Scene API & YAML Persistence (`/api/overlays/studio`)**: `GET`/`POST`/`PUT` endpoints with input sanitization (`normalizeStudioScene`), `config.yaml` persistence under `studio`, and reserved `"studio"` ID protection for custom overlays.
- **Studio Unit Tests (`server/studio.test.ts`)**: Automated test coverage for scene dimension clamping, path sanitization, self-reference prevention, and reserved overlay ID protection.

### Changed
- **Navigation & Marketplace Integration**: Added `[ OVERLAY STUDIO ]` tab to `Sidebar`, quick `OPEN STUDIO COMPOSER` button in `OverlaysTab`, `/overlays` dev proxy in `vite.config.ts`, and widened `.app-layout` to `1440px`.
- **Documentation**: Updated `docs/overlays.md` with Overlay Studio setup and OBS Browser Source instructions.

## Key Files Changed
- `src/components/StudioTab.tsx` - Visual overlay composer stage, layer stack, and inspector
- `server/routes/overlays.ts` - `/overlays/studio/` OBS Browser Source renderer and `/api/overlays/studio` endpoints
- `server/config.ts` - `normalizeStudioScene` validation and `config.yaml` serialization
- `server/services/overlays.ts` - Reserved `"studio"` ID guard in `createCustomOverlay`
- `src/App.tsx`, `src/components/Sidebar.tsx`, `src/components/OverlaysTab.tsx`, `src/App.css` - Studio navigation, state sync, and RawBlock styling
- `server/studio.test.ts` - Unit tests for Studio normalization and safety
- `docs/overlays.md` - Overlay Studio documentation
