# Release Notes - v0.1.6

**Release Date:** 2026-11-12  
**Version:** 0.1.6  
**Bump Type:** patch

## Summary

Release v0.1.6 introduces the Overlay Studio scene composer with saved profiles, Git repository overlay pulling with auto-generated IDs, OS-native folder open buttons, and comprehensive security hardening across server APIs.

## What's Changed

### Added
- **Overlay Studio Scene Composer**: Compose, rearrange, and scale multiple overlays into a unified OBS browser source (`/overlays/studio/`).
- **Studio Profiles**: Save, manage, and switch between named layout profiles with deep-linking (`?page=studio&profile=<id>`) and explicit **LOAD PROFILE** control.
- **Git Pull with Auto-Generated IDs**: One-click overlay installation from Git URLs with automatic repo slug detection and fallback to ZIP downloads.
- **OS-Detected Folder Openers**: Instant buttons to open local overlay directories in macOS Finder, Windows Explorer, or Linux File Manager.

### Changed
- **CORS Hardening**: Enforce strict origin validation allowing only desktop webviews and local loopback origins; external web pages are blocked from `/api/*`.
- **Sensitive Secret Masking**: Spotify client secrets and refresh tokens are masked (`••••••••`) over read APIs and Server-Sent Event broadcasts.
- **Safe Command Invocation**: Replaced shell string interpolation with argument-bounded `execFile` to eliminate command injection vectors.

### Fixed
- **SSRF Prevention**: Prohibit webhooks targeting cloud metadata services (`169.254.169.254`, `metadata.google.internal`) or loopback API ports.
- **CI Test Runner**: Automated test server boot in GitHub Actions Shannon security scanner.

## Key Files Changed
- `src/components/StudioTab.tsx` — Overlay Studio composer, profile management, and interactive stage.
- `server/routes/overlays.ts` — Studio scene endpoints, profile persistence, and unified OBS rendering.
- `server/services/overlays.ts` — Safe Git cloning, zip extraction, and OS folder opening.
- `server/index.ts` & `server/services/webhook.ts` — CORS origin guards and webhook SSRF validation.
- `server/config.ts` & `server/routes/status.ts` — Sensitive credential masking and configuration synchronization.
