# Release Notes - v0.1.9

**Release Date:** 2026-11-12  
**Version:** 0.1.9  
**Bump Type:** patch

## Summary

Release v0.1.9 introduces external HTTP/HTTPS overlay layers in Overlay Studio, optional TikTok LIVE danger-zone layout guides, and comprehensive security hardening against cloud metadata harvesting and same-origin iframe sandbox escapes.

## What's Changed

### Added
- **External Overlay Layers**: Embed remote HTTP/HTTPS overlays as sandboxed iframe layers with full positioning, resizing, ordering, and profile persistence.
- **TikTok LIVE Danger-Zone Guides**: Canvas-scaled overlay guides highlighting standard header, control, and chat/gift boundaries for vertical streaming.
- **Automated Validation Test Suite**: Expanded unit tests in `server/studio.test.ts` verifying external layer URL validation and profile transitions.

### Changed
- **Iframe Sandboxing**: External layers are served with `sandbox="allow-scripts allow-same-origin"` and `referrerpolicy="no-referrer"` to limit external script capabilities while maintaining compatibility.
- **Editor Feedback**: Immediate inline feedback in Studio for invalid or restricted external overlay URLs.

### Fixed
- **Cloud Metadata SSRF Protection**: Prohibited external layer URLs targeting cloud metadata services (`169.254.169.254`, `metadata.google.internal`, link-local ranges).
- **Same-Origin Sandbox Escape Prevention**: Disallowed external layers targeting the bridge application's own API port (`3001`), preventing local iframe sandbox breakouts.

## Key Files Changed
- `src/components/StudioTab.tsx` — External layer input controls, danger-zone guide toggle, and URL validation.
- `server/config.ts` — `isValidExternalLayerUrl()` validation and Studio scene normalization.
- `server/routes/overlays.ts` — Sandboxed OBS iframe rendering and host/port safety guards.
- `server/studio.test.ts` — External layer URL and security test coverage.
- `docs/overlays.md` — External overlay and danger-zone guide documentation.
