# donate-socket Release Notes - v0.1.8

**Release Date:** 2026-11-12  
**Version:** 0.1.8  
**Bump Type:** patch

## Summary

Overlay Studio adds optional TikTok LIVE danger-zone guides for positioning overlays away from common viewer-interface areas.

## What's Changed

### Added
- Toolbar toggle for approximate header, right-side controls, chat/gifts, and bottom-bar guides.
- Canvas-scaled, pointer-transparent guides that remain editor-only.
- Explicit warning that actual TikTok UI varies by device and LIVE layout.

## Key Files Changed
- `src/components/StudioTab.tsx` — guide toggle and canvas regions.
- `src/App.css` — guide visibility and pointer-transparent styling.
- `docs/overlays.md` — usage and calibration limits.
- `package.json` and `src-tauri/` version metadata — version 0.1.8.
