# donate-socket Release Notes - v0.1.18

**Release Date:** 2026-11-20  
**Version:** 0.1.18  
**Bump Type:** patch

## Summary

Completed Thai UI localization, automatic 30-second TikTok LIVE room polling, Windows `%APPDATA%` config migration, SSRF/TTS/CI security hardening, and consolidated CI/release workflows.

## What's Changed

### Added
- Full Thai UI translations (`src/i18n.tsx`) across Dashboard, Config, Overlays, Overlay Studio, About, sidebar status chips, and banners, backed by `tests/i18n.test.ts`.
- Automatic 30-second live polling (`LIVE_CHECK_INTERVAL_MS`) in `server/services/tiktok.ts` that waits cleanly while offline, auto-connects when live, resumes polling on `STREAM_END` or disconnect, respects `retryAfter`, and stops on `InvalidUniqueIdError`, backed by `server/tiktok.test.ts`.
- Shared `classifyBlockedHost()` helper (`server/utils.ts`) and IPv6/IPv4-mapped SSRF regression assertions (`tests/security.test.ts`, `server/studio.test.ts`).
- Windows portable ZIP packaging step (`donate-socket_<version>_x64-portable.zip`) in `.github/workflows/release.yml` alongside macOS (`aarch64` + `x86_64`) and Linux builds.

### Changed
- Consolidated macOS Apple Silicon and Intel release steps in `.github/workflows/release.yml` and upgraded GitHub Actions workflows (`release.yml`, `security.yml`) to Node 24 (`actions/checkout@v7`, `actions/setup-node@v7`, `github/codeql-action/*@v4`) with Bun (`oven-sh/setup-bun@v2`).
- Switched Windows packaged `config.yaml` resolution to `%APPDATA%\dethz-lab\dethz-socket` and added one-time non-destructive migration from legacy `zip.kizuna.donate\config.yaml` (`src-tauri/src/lib.rs`).
- Updated `README.md` and `docs/` (`architecture.md`, `webhooks.md`, `latest-features.md`, `build-and-release.md`, `security-audit.md`) to match current features, schemas, and security controls.

### Fixed
- Stripped IPv6 brackets and blocked link-local, metadata, and IPv4-mapped IPv6 loopback hosts across `validateWebhookUrl()`, `isValidExternalLayerUrl()`, `STUDIO_OBS_HTML`, and `StudioTab.tsx`; disabled HTTP redirects (`redirect: "error"`) on webhook `fetch()`.
- Replaced chained TTS template replacements with single-pass regex substitution over `{nickname}`, `{username}`, and `{comment}` (`server/services/tiktok.ts`).
- Hardened `tFor()` with `Object.prototype.hasOwnProperty` lookup so prototype keys fall back safely (`src/i18n.tsx`).
- Fixed CI dependency scanning (`bun audit`) in `.github/workflows/security.yml` and passed `VERSION` via step `env:` in `.github/workflows/release.yml`.
