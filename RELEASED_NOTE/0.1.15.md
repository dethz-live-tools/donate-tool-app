# donate-socket Release Notes - v0.1.15

**Release Date:** 2026-11-16  
**Version:** 0.1.15  
**Bump Type:** patch

## Summary

Split webhook endpoints per event type, portable Windows build, and hidden backend terminal with in-app bridge indicator.

## What's Changed

### Added
- Split webhooks: `webhook.uri` now delivers TikTok gifts only. Optional `webhook.uri_chat` (TikTok chat/TTS events) and `webhook.uri_spotify` (Spotify song-change events) each fall back to the gift URL when empty. Configured in the app config page or config.yaml.

### Changed
- GitHub release workflow now also builds a Windows portable `.exe` (no installer) alongside NSIS and MSI bundles.

### Fixed
- Backend server process no longer pops up a terminal/console window on Windows (`CREATE_NO_WINDOW`); the sidebar now shows a BRIDGE: ONLINE/OFFLINE indicator fed by the API/SSE connection state.

## Key Files Changed
- `server/services/webhook.ts` — per-type webhook URL selection (gift/tts/spotify).
- `server/config.ts` — `uri_chat`/`uri_spotify` parse, merge, serialize.
- `src/components/ConfigTab.tsx` + `src/App.tsx` — separate webhook URI fields and state.
- `src-tauri/src/lib.rs` — hidden backend process on Windows.
- `src/components/Sidebar.tsx` + `src/App.tsx` — backend bridge online indicator.
- `.github/workflows/release.yml` — Windows bundles now include `portable`.
- `package.json`, `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml` — version 0.1.15.
