# donate-socket Release Notes - v0.1.17

**Release Date:** 2026-11-17  
**Version:** 0.1.17  
**Bump Type:** patch

## Summary

Internationalization (Thai language support for the core UI with language switcher) and Windows CI compilation fix.

## What's Changed

### Added
- i18n layer (`src/i18n.tsx`): dependency-free EN/TH dictionaries, React context provider, `t()` helper with English fallback.
- Language selector (ENGLISH / ไทย) in the sidebar SYSTEM STATUS area; choice persisted to localStorage.
- Thai translations for core shell: sidebar navigation, status chips (BRIDGE / TIKTOK / SPOTIFY), configuration tab labels and buttons, about page (version + update status), and log filter buttons.

### Fixed
- Fixed Windows compilation error in `src-tauri/src/lib.rs` by importing `std::os::windows::process::CommandExt` for `CREATE_NO_WINDOW` process flags.
- Added `--windows-hide-console` to Bun backend compilation in `scripts/build-backend.ts`.

## Key Files Changed
- `src-tauri/src/lib.rs` — Windows `CommandExt` trait import.
- `scripts/build-backend.ts` — `--windows-hide-console` compile flag.
- `src/i18n.tsx` — dictionaries, context, provider, `useLang` hook.
- `src/App.tsx` — `LangProvider` wrapper.
- `src/components/Sidebar.tsx` — nav labels, status chips, language selector.
- `src/components/ConfigTab.tsx` — labels and buttons.
- `src/components/AboutTab.tsx` — version/update status strings.
- `src/components/DashboardTab.tsx` — log box headers and filter tabs.
- `package.json`, `src-tauri/tauri.conf.json`, `src-tauri/Cargo.toml` — version 0.1.17.
